| **Description:**
| *An analysis module for calculating velocity autocorrelation functions (VACF) and velocity density of states (VDoS) from MD trajectories.*



Installation instructions
=========================

The latest version of trvdos can be installed using the following:

.. code-block:: bash

    mamba install gsl
    pip install trvdos

The source code of trvdos can be installed using the following:

.. code-block:: bash

    mamba install gsl
    pip install git+https://github.com/HeydenLabASU-collab/trvdos@main
